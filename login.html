We never store your Reddit login details. Authentication is securely handled by Reddit via OAuth. ModBot receives limited access tokens through Reddit’s official API, enabling bot features like post tracking, mod actions, and community insights—only within the scopes you approve.

First Time Setup Instructions

  1. Create a Reddit account for the bot
    Make a new Reddit user account like ModBotHelper. This account will perform actions on your sub.
  2. Add it as a moderator
    Go to r/YOURSUB/about/moderators and add the bot with these permissions:
    • Posts – to comment, remove, or edit content
    • Flair – to apply user or post flairs
    • Config – to read subreddit settings
    • ModLog – to respond to rule triggers or track actions
    Optional: You may also enable:
    • Wiki – if the bot uses wiki-based rules
    • Mail – if integrating with modmail alerts
  3. Register an App on Reddit
    Log in as the bot, visit reddit.com/prefs/apps, and create a Web App with:
    • Name: ModBot
    • Redirect URI: Your login callback URL (e.g., https://modbot.io/callback)
    Save your client_id and client_secret.
  4. Request the proper OAuth scopes
    When authenticating, include scopes like: identity, read, modposts, modconfig, submit, modlog, modflair

ModBot uses these permissions only to automate moderation tasks you explicitly configure—nothing more.
